# مجلد شعارات المنصات

ضع هنا صور المنصات بصيغة **PNG** بهذه الأسماء بالضبط (الأسماء مرتبطة بالكود في
`src/data/mockData.js` — أي اختلاف في الاسم يعني أن الشعار لن يظهر):

| اسم الملف المطلوب | المنصة |
|---|---|
| `quotex.png` | Quotex |
| `pocket-option.png` | Pocket Option |
| `iq-option.png` | IQ Option |
| `binance.png` | Binance |
| `okx.png` | OKX |
| `metatrader-4.png` | MetaTrader 4 |
| `metatrader-5.png` | MetaTrader 5 |

## المواصفات

- **المقاس:** ‎96×96‎ بكسل (يُعرض بحجم 24×24، والمقاس الأكبر لدعم شاشات Retina)
- **الخلفية:** شفافة (transparent)
- **الشكل:** مربّع، والشعار في المنتصف مع هامش داخلي بسيط
- **الحجم:** يفضّل أقل من 20KB لكل ملف حفاظًا على سرعة التطبيق

## السلوك عند غياب الصورة

الكود يتعامل مع الملفات الناقصة تلقائيًا: إذا لم يُعثر على الصورة، تظهر مكانها
البطاقة النصّية القديمة (`Q` / `PO` / `IQ` …) بدل مساحة فارغة أو أيقونة مكسورة.
يعني التطبيق يعمل بشكل سليم قبل وبعد إضافة الصور.

## إضافة منصة جديدة

أضف السطر في `src/data/mockData.js` داخل مصفوفة `PLATFORMS`:

```js
{ name: 'Deriv', mark: 'D', logo: '/platforms/deriv.png' }
```

ثم ضع الملف `deriv.png` في هذا المجلد.

## ملاحظة قانونية

شعارات هذه المنصات علامات تجارية مسجّلة لأصحابها. استخدامها للإشارة إلى التوافق
التقني مقبول عمومًا، لكن تجنّب أي تنسيق يوحي بأن المنصة راعية للتطبيق أو شريكة
فيه أو معتمدة له. بعض المنصات (مثل Binance و OKX) تنشر إرشادات استخدام للعلامة
التجارية على مواقعها — راجعها قبل النشر.
